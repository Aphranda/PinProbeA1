三、原因分析

触发条件： 门体末段装配缓冲棉条，门到位前需减速缓冲，末段限位触发偏慢，全行程因此需要 3850 ms（现场机构说明，与设备记录的行程时间一致）。而上位机指令周期为 3.0 s，6 次关门全部在约 74% 处被下一条开门指令打断——开门指令恰好落在末段缓冲区内；而"门关到底"是"关门进行中"这一状态唯一的正常结束方式。

直接原因： 自动回退的执行条件是"门已开到位 且 设备处于空闲待机状态"，而设备流程在 44 s 内始终停留在"关门进行中"，自动回退的判定一次都没有执行。这与"USB 显示已插入"并不矛盾——该状态由"输出 + 到位传感"推导，其中有一条只看门上限位传感的兜底判断，所以门开着、USB 插着时，状态查询仍显示正常。

改进因此分两处：门的位置需要能自动纠正；回退的判定不应只依赖单一的流程状态。见下章。

四、优化方案

目标： 门一旦开到位就保证 USB 回到回退位置；门的位置与设备流程状态不一致时，设备应自行纠正，而不是停在中间状态等待复位。

编号改进项改进后现场效果
O1位置纠正门已开到位、且没有正在执行的关门动作、也没有待执行的关门意图时，流程自动回到空闲待机中途开门、断电复气后开门都能自行恢复到可操作状态；判定依据是门的位置而不是时间，不受末段缓冲减速影响
O2回退条件调整执行条件改为"门已开到位 + USB 仍处于插入状态 + 无关门意图"门开到位后 USB 必定回退，不再依赖单一流程状态
O3异常提示未执行与未到位分别给出明确告警，并带原因与耗时可一眼分清"没有执行"与"执行失败"
O4失败可恢复安全条件满足时允许自动重试一次；仍失败则告警并保持状态可查询偶发一次不到位，不会让 USB 永久留在插入状态

安全保护不变：急停、激光防夹、断电回锁与到位反馈都不受影响；接口指令与返回值定义不变；自动回退仍以"门已开到位"为安全前提。

自检方法（关门到位、绿灯亮起后发一次开门指令，再依次查询）： READ:SYSTem:STATe? 期望回到 IDLE；READ:CYLInder2:STATe? 期望数秒内变为 OPENED；若显示 CYL ERR，属"已执行但未到位"，请按告警原因检查回退机构与到位传感。

五、验收与关注点
编号场景通过判据
A1关门到位后发开门指令USB 自动回退，状态查询与实际位置一致
A2关门过程中发开门指令门开到位后流程回到空闲待机，并自动回退
A3人为制造回退到位传感异常出现明确告警（含原因），状态可查询
A4制造一次回退不到位后恢复正常自动重试一次后到位；仍失败则告警且保持可操作

关注点： ① 门体末段装配缓冲棉条、到位前减速明显，设备对关门时间的判断（含防夹检测窗口）以完整行程为准——本次记录的 3850 ms 即为含缓冲的全行程时间；② 连续指令开关门（关门未完成即反向开门）不属于正常操作工况，且开门指令落在缓冲段内，对机构与气压损耗更大，建议上位机脚本改为"等到位再发下一条"；③ 该自动流程的实机验收基线将随 A1～A4 一并建立。

本次为自动回退未被触发，机械与传感链路正常；整改以门位置纠正与回退条件调整为主线，同时补齐告警与重试；安全保护逻辑保持不变。
