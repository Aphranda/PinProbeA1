## 一、失效结论

:::chips
损伤器件 | U3 TPS7A2033（输入侧碳化）+ U1 CH318（电源域低阻 2~3Ω）
失效机理 | 端口电流持续灌流（芯片内 I²R 0.6~2.5 W）
失效链 | VCC5V 过压击穿 U3 输入级，并经导通的调整管同时作用于 3.3V 电源域；随后端口电流经缺口持续灌流，将 U3 烧成碳化
影响范围 | 主机变体（整机 5V 直接取自 PC USB 口）
:::

:::note
**结论：** 本次失效源于 **VCC5V 输入端的一次过能量事件**。该能量在 U3 输入侧形成对地低阻通路（VIN↔GND），随后 **PC USB 端口电流持续灌流**，将 U3 输入侧烧成碳化；同一股能量经 U3 输出传至 3.3V 电源域，将 U1（CH318）电源域击穿为 2~3Ω 低阻。全板损坏器件为这两颗芯片，其余无源器件与电容经逐个实测均正常。能量方向为 **VCC5V 输入侧 → U3 → 3.3V 电源域**。根因位于主机 5V 取电链路：输入侧钳位电压高于 U3 的 6.5V 输入窗口上限，取电路径未设过流保护。
:::

### 1.1 实测确认的事实

| 事实 | 读数 / 观察 | 判读 |
| --- | --- | --- |
| U3 内部存在 VIN↔GND 低阻 | 拆 U3 **前** `VCC5V→GND` 低阻；拆 U3 **后** 恢复高阻 | 低阻通路位于 **U3 内部**；输入侧无源器件实测正常 |
| U3 烧损分布 | 封装碳化集中在 **VIN 一处**，OUT 侧形貌完好 | 能量落点为 **输入侧硅/键合线** |
| U1 电源域低阻 | 拆 L2 后 `VDD3V3→GND` **2~3Ω**；拆 C6、C7 后**同为 2~3Ω**；**U1 外观完好** | 低阻位于 **U1 内部 VDD3V3↔GND**，为局限于硅内的微小熔融通道 |
| U1 引脚分布 | 低阻集中在 **供电脚 VDD3V3**，其余引脚对地读数正常 | 能量落点为 **U1 电源域** |
| LDO 输出节点 | `$1N64`（C12/C14）对地**高阻** | 输出侧电容实测正常，全板损伤集中于上述两颗芯片 |

### 1.2 能量核算：碳化形貌对应"持续灌流"能量级

| 能量来源 | 量级 | 对应形貌 |
| --- | --- | --- |
| ESD 接触放电 8kV（150pF/330Ω） | 储能 ½CV² ≈ **4.8 mJ**，峰值 ~30A、持续 ~100ns | 微米级熔融孔/熔丝，高度局部 |
| 浪涌 8/20µs（1kV 级）灌入钳位 | **10~100 mJ** | 局部击穿与熔融 |
| **PC USB 端口电流持续灌流**（实测通路 2~3Ω） | 端口限流 0.5~1A 时芯片内 I²R = **0.6~2.5 W**，每秒 0.6~2.5 J | **塑封料碳化、键合线熔断（与现场照片一致）** |

持续灌流的能量比瞬态高 **2~3 个数量级**：瞬态提供击穿所需的电压缺口，碳化形貌由端口随后提供的持续电流形成。U1 处同为 2~3Ω，两处损伤属同一能量级。

### 1.3 触发条件

触发条件为 **VCC5V 上的瞬态过压**（插拔浪涌振铃 / 接触放电 / 地电位反弹），其峰值超过 U3 的 **6.5V** 输入绝对最大额定。判定依据：

| 判定依据 | 实测 / 数据 |
| --- | --- |
| 输入侧钳位能力 | U12/U13 为小尺寸 ESD 器件：该类 5V 档器件 V_BR 最低 6.0~6.4V，1A 事件电流下钳位可达 9.8~10V，高于 U3 的 6.5V 窗口上限 |
| 过流保护 | 取电路径未设保险丝等过流保护环节 |
| 器件耐受 | U3 的 ESD 额定为器件级（HBM ±2000V、CDM ±750V）；击穿由 ns~µs 级瞬态完成，快于限流与热关断的响应时间 |
| 现场情况 | 出厂前工作正常、现场首次插上即坏、损坏集中于主机（其 5V 直接取自 PC USB 口） |

## 二、网表核对与供电回路

供电支路网表（节选）：

```text
VCC5V     ; C8.2 C13.2 F2.2 R1.2 U3.1 U3.3 U4.2 U5.2      ← 输入侧：C8 1uF ∥ C13 10uF
'$1N64'   ; C12.2 C14.2 L2.1 U3.5                         ← U3 输出 → L2 → VDD3V3 → U1.16
VDD3V3    ; C6.2 C7.2 R2.2 R9.2 U1.16                     ← CH318 电源域（U3 输出的唯一下游负载）
VCC5V_OUT ; C10.2 C11.2 C19.1 C20.1 F2.1 L4.2 R6.2        ← 从机降压 5V，须经 F2 才接入 VCC5V
'$1N114'  ; U4.1 U12.2 USB1.1                             ← 主机 VBUS：U12(ESD) + U4(磁珠)
VCC12V    ; CN1.1 D3.1 D4.2 D5.1 F1.2 RJ1.5~RJ1.8         ← 12V 侧：TVS + F1 保险丝
```

![图 1　主机供电回路：整机仅由 PC USB VBUS 取电（失效机为本回路）](diagrams/主机供电回路.svg)

**要点：** 主机变体下整机 5V 只经过 `VBUS → U12/U13（小尺寸 ESD）→ U4/U5（磁珠）→ C8/C13 → U3`；`VDD3V3` 在板上只连 C6/C7/R2/R9/U1.16，是 **U3 输出的唯一下游负载**，U1 处的能量来自 U3 的输出。

### 2.1 机型判定（失效机＝主机）

| 变体 | 供电来源 | R9 | R8 | R11 | R10 | F2 | 与 VCC5V 的关系 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| **主机（失效机）** | **仅 PC USB VBUS** | 贴装 | 空贴 | 空贴 | 贴装 | 空贴 | !!12V 支路物理断开!! |
| 从机 | 仅 VCC12V | 空贴 | 贴装 | 贴装 | 空贴 | 贴装 | 12V 降压为唯一 5V 来源 |

R9/R8 互斥设置 CH318 主/从角色（VDD3V3/GND ↔ U1.13）；R11/R10 互斥使能或关断本机 12V→5V 降压（U2.3）；F2 贴装时降压 5V 并入 VCC5V。失效机为**主机**，整机出厂前工作正常，5V 由 PC USB VBUS 单独供电，12V 支路与 VCC5V 物理断开。

## 三、失效链与判断依据

### 3.1 实测判定结果

| 部位 | 实测结果 | 判定 |
| --- | --- | --- |
| 全部 MLCC（C6/C7/C8/C12/C13/C14） | 对地高阻、无漏电 | 正常 |
| 输入侧无源器件（U12/U13/U4/U5） | 拆 U3 后 `VCC5V→GND` 恢复高阻 | 正常 |
| LDO 输出侧（C12/C14、`$1N64`） | 对地高阻 | 正常 |
| 3.3V 电源域 | 拆 L2、拆 C6/C7 后仍为 2~3Ω | 损伤位于 **U1 内部** |
| 12V 支路 | 主机空贴 F2、降压关断 | 与 5V 取电回路物理隔离 |
| 能量落点 | 碳化集中于 U3 的 VIN 一侧，OUT 侧形貌完好 | 能量自输入侧进入 |

### 3.2 失效链

> **VCC5V 出现超出 U3 承受能力的过压事件。该过压同时作用于两级：① 击穿 U3 输入级硅内结构（VIN↔GND 低阻），并经处于导通状态的调整管跟随至输出，将 `VDD3V3` 抬升至超过 CH318 的电源绝对最大额定，U1 电源域被击穿为低阻（2~3Ω，外观完好）；② 缺口形成后，PC USB 端口电流经该缺口持续灌流，将 U3 输入侧烧成碳化（VIN 单点）。**

这条链一次事件即完整对应全部实测事实，并与"只有主机损坏"的现场情况吻合：主机整机 5V 只来自 PC USB 口，取电链路仅有能力不足的 ESD 钳位、无过流保护；从机 5V 来自本地 12V 降压，前端有 TVS + F1，且插拔发生在从机/DUT 侧，风险集中于主机。

**过压如何到达 3.3V 电源域：** 线性稳压器在输入过压期间输出跟随输入电位（仅相差调整管的导通压降），其内部保护中的限流与热关断分别面向过流与过热。因此 VCC5V 上的瞬态过压经调整管同时施加于 3.3V 电源域，VDD3V3 随之上抬至超过 CH318 的电源绝对最大额定，U1 的 VDD 结被击穿为 2~3Ω。此外，输出侧的 C12/C14 与 L2、C6/C7 构成 LC 网络，瞬态下 VDD3V3 节点的过冲可高于输入端，该节点的电压应力由两级共同承受。

**能量分配与热点位置：** U3 输入侧的击穿点跨接于 VCC5V 与 GND 之间，端口电流经此流入地，功率 I²R = 0.6~2.5W 集中于输入侧硅与键合线的极小体积内，并以秒级持续时间作用，因此形成碳化形貌。U1 承受的是同一过压经调整管跟随过来的瞬态能量（mJ 量级），仅形成微小熔融通道，外观保持完好。两处阻值同量级、形貌不同，对应能量沉积量的差异。

**两处低阻通路的形成时机：** 出厂前整机工作正常；若 2~3Ω 在出厂时即存在，3.3V 轨处于 1.3V 量级（折叠限流 0.52A × 2.5Ω），整机无法工作。据此，两处低阻通路均为本次事件中形成。

### 3.3 能量方向

| 项目 | 数值 | 说明 |
| --- | --- | --- |
| U3 输出侧为 2~3Ω 时的工作状态 | 折叠限流 ISC **0.16A**、VOUT ≈0.4V、芯片内功耗 **0.74W** | 数据手册参数，见 3.4 |
| 该状态下的结温 | 升幅 +138°C（θJA 187.1°C/W），落于 TSD(165°C) 门槛 | 对应限流/热关断循环 |
| VIN 引脚碳化对应的电流 | **0.5~1A 持续电流** | 对应 1.2 节的碳化能量级；通路为实测确认的 U3 内部 VIN↔GND 低阻 |
| 3.3V 电源域的电压应力 | 瞬态过压经导通的调整管跟随至 VDD3V3；C12/C14 + L2 + C6/C7 的 LC 网络可使该节点过冲高于输入端 | 对应 U1 的 VDD 结击穿（2~3Ω，外观完好） |
| 能量方向 | **VCC5V 输入侧 → U3 / 3.3V 电源域（同一过压同时作用）** | 与 3.1 的能量落点实测结果一致 |

### 3.4 器件耐受能力（依据 TI TPS7A20 数据手册 SBVS338H）

| 参数 | 数值 | 与本案的关系 |
| --- | --- | --- |
| VIN 绝对最大额定 | **6.5 V** | 可用设计窗口为 5.25~6.5V，窗口宽度 **1.25V** |
| VOUT 绝对最大额定 | **min(6.5V, VIN+0.3V)** → 5V 输入时为 **5.3V** | 输出被外部抬至 5.3V 以上即超出额定 |
| 内部限流 | 折叠限流 ICL **360 / 520 / 770 mA**；短路限流 ISC **160 mA**（typ） | 3.3 节计算依据 |
| 热关断 TSD | **165°C 关断 / 140°C 复位** | 数据手册原文：故障持续时 *"cycles between current limit and thermal shutdown"* |
| ESD 额定 | **HBM ±2000V、CDM ±750V（器件级）** | 器件级额定面向生产与装配环节，系统级浪涌防护由板级钳位器件承担 |
| θJA（DBV/SOT-23-5） | **187.1 °C/W** | 3.3 节结温计算依据 |
| DBV 引脚定义 | 1=IN、2=GND、3=EN、**4=N/C**、5=OUT | 该封装 pin4 为 N/C（无 NR/SS 功能） |
| **输入侧现有防护** | U12/U13（DFN1006-2L 小尺寸 ESD，钳位于 VBUS） | 该类器件面向接触放电级 ESD；V_BR 最低 6.0~6.4V，1A 事件电流下钳位可达 9.8~10V，钳位电平高于 U3 的 6.5V 窗口上限 |
| **过流保护** | 主机空贴 F2，取电路径未设保险丝 | 击穿后由 PC 端口限流持续灌流，故障持续发展 |

![图 2　现场失效照片：TPS7A2033 输入侧（VIN 附近）碳化形貌，OUT 侧形貌完好](evidence/TPS7A2033_failure_vin.png)

:::bar
**结论：** 失效为**单次过能量事件造成的级联损伤** —— 能量从 **VCC5V 输入侧**进入 U3 打开缺口，再由 **PC USB 端口电流持续灌流**烧成碳化，并沿供电链将 **U1（CH318）电源域**一并击穿（2~3Ω）。能量方向为 VCC5V 输入侧 → U3 → 3.3V 电源域。根因位于**主机 5V 取电链路的输入防护能力不足**：输入侧钳位电平高于 U3 的 6.5V 输入窗口上限，取电路径未设过流保护，故障在端口限流下持续发展，一次超出 U3 输入能力的事件即造成芯片级永久损伤。
:::

## 四、输入侧防护优化方向（摘要）

:::chips
设计窗口 | 5.25V（不得导通）～ 6.5V，宽度 1.25V
钳位器件 | ESD441DPLR（0.9A → 6.28V，5A → 6.5V）
过流保护 | 保险丝 0.25A 慢熔（可选 PTC），置于 VCC5V → U3 支路
实施位置 | 钳位器件与本地电容置于保险丝之后、紧贴 U3 的 VIN
:::

:::note
选型要点：5V 档 TVS/ESD 器件的击穿电压 V_BR 最低为 6.0~6.4V，导通点已贴近 6.5V 窗口上限，再叠加动态电阻压降即超出窗口。因此选型以动态电阻 R_DYN 为准（电源线对电容不敏感），低钳位 ESD 器件是窗口内的可用方案：ESD441DPLR 在 0.9A 下钳位 6.28V、5A 下 6.5V。
:::

### 4.1 候选器件对比（规格书核对）

| 器件 | 类型 / 封装 | 钳位 @0.9A | 钳位 @5A | 动态电阻 R_DYN |
| --- | --- | --- | --- | --- |
| **ESD441DPL** | 单向 / 0201 | **6.28V** | **6.5V**（TLP） | **0.1Ω** |
| ESD441DPY | 单向 / 0402（兼容现板焊盘） | 7.07V | 7.3V | 更低 |
| SMF5.0A | 单向 TVS / SMA | 6.80V | ≈7.3V | 0.115Ω |
| RCLAMP0521T-ES | 双向 / 0.3pF 低电容 | 9.8V（外推） | — | 2.0Ω |
| TPD4S012（VBUS 脚） | 四路 ESD 阵列 | 不导通 | — | — |

### 4.2 保护边界（单颗 ESD441DPL）

| 事件电流 | 钳位电压 | 判定 |
| --- | --- | --- |
| ≤1A | 6.3V | 窗口内 |
| 5A | 6.5V | 窗口上限 |
| 8/20µs 6A | 7.6V | 超出窗口，持续时间由保险丝限制 |

### 4.3 实施要点

| 项 | 内容 |
| --- | --- |
| 钳位器件与本地电容 | ESD441DPLR 与 ≥1µF（建议 10µF）电容置于**保险丝之后、紧贴 U3 的 VIN**；现有 C8/C13 位于 VCC5V 侧，需移一颗至该位置 |
| 过流保护 | 主机 0.25A 慢熔（或 PTC）、从机 1A。置于 LDO 输入支路（VCC5V → U3）可用一支规格覆盖两种机型（该支路电流 ≤80mA） |
| 配合验证 | 5A/20µs 事件的 I²t ≈ 5×10⁻⁴ A²s，低于 0.25A 慢熔丝耐受值，钳位器件的瞬态电流不会造成误断 |
| 电源回路 | 不串电阻，避免压降与发热 |
| 备选方向 | 事件能量达数 A 级时：① 换更高输入耐压的 LDO（18V/36V 级），窗口放宽后 SMF5.0A 单级即可满足；② 加 OVP 开关（5.8V 门限、µs 级断开），以切断替代钳位 |

**保护链分工：** 短时瞬态由钳位器件吸收；持续过流与短路（如 3.2 节确认的缺口灌流）由保险丝切断该支路电流，从源头限制沉积能量。
