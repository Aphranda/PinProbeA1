## 一、结论摘要

:::chips
保护目标 | LDO 输入 < 6.5V
设计窗口 | 5.25V（不得导通）～ 6.5V
钳位器件 | ESD441DPLR（6.28V @0.9A）
过流保护 | 保险丝（防扩大）
:::

:::note
**核心结论：** 在候选器件中，**只有 ESD441DPLR 能在 0.9A / 5A 量级把电压钳在 6.5V 以内**（0.9A→6.28V、5A→6.5V@TLP）；其余单颗均不满足：SMF5.0A 6.80V、ESD441DPY 7.07V、H5VU06BS 约 6.5–7V、RCLAMP0521T-ES **9.8V**、TPD4S012（VBUS 脚）**根本不导通**。保险丝的作用是 **防扩大（击穿后不被持续灌流）**，它**不提供任何电压钳位**。
:::

### 1.1 关键选型要点

| 要点 | 内容 |
| --- | --- |
| 器件取向 | **低钳位优先于低电容**：VBUS 是电源线，电容不敏感；低电容器件的动态电阻往往大 10～20 倍 |
| 动态电阻 | 目标 R_DYN ≤0.2Ω；ESD441DPL 0.1Ω、SMF5.0A 0.115Ω、RCLAMP0521T-ES **2.0Ω** |
| 能量能力 | 浪涌能量由大功率器件承担：SMF5.0A 200W 级 vs ESD441 6A/45W 级 |
| 过流保护 | 保险丝串在 **LDO 输入支路**（VCC5V → U3）；该支路主机/从机均为 ≤80mA，**一个规格覆盖两种变体**（表 5-1） |
| 封装取舍 | ESD441**DPL**=0201 钳位更低但需改焊盘；**DPY**=0402 兼容现板焊盘但钳位高约 0.8V |

## 二、问题定义与设计窗口

| 项 | 数值 | 含义 |
| --- | --- | --- |
| 被保护器件 | U3 = TPS7A2033，**VIN 绝对最大额定 6.5V** | 保护上限 |
| 母线正常上限 | VBUS 5.25V（USB 5V±5%） | 保护器件**在此电压下不得导通** |
| 可用设计窗口 | **1.25V** | 决定了"单靠被动器件钳位"极难成立 |

窗口为什么窄：任何 5V 档 TVS/ESD 器件的**击穿电压 V_BR 最低也在 6.0～6.4V**（低于 5.5V 会在正常工作时漏电/微导通），"导通点"已经贴着 6.5V，再叠加动态电阻压降就必然超限：

| 器件类型 | V_BR | 事件电流 1A 时的钳位 | 是否 <6.5V |
| --- | --- | --- | --- |
| 普通 5V TVS（SMF5.0A 类） | 6.4～7.0V | 6.8～7.1V | ✗（临界） |
| 低钳位 ESD（ESD441DPL） | 6.0～8.0V | **6.28V** | ✓ |
| 高速数据线 ESD（RCLAMP 类） | 6.0V | 9.8～10V | ✗ |

## 四、保护器件选择与保护边界

**表 4-1　推荐器件**

| 项 | 选择 | 依据 |
| --- | --- | --- |
| 钳位器件 | **ESD441DPLR**（0201，需改焊盘） | 唯一在 0.9A/5A 量级满足 <6.5V 的候选；V_RWM 5.5V、漏电 50nA、±30kV |
| 兼容替代 | ESD441**DPYR**（0402，兼容现板焊盘） | 钳位 7.07V@0.9A，引脚兼容备选 |
| 大能量需求 | SMF5.0A（200W 级） | 事件电流可达几 A 时由它承担能量 |

**表 4-2　保护边界（单颗 ESD441DPL）**

| 事件电流 | 钳位电压 | 是否 <6.5V | 说明 || --- | --- | --- | --- |
| ≤1A | 6.3V | **✓** | 覆盖 ESD 与小幅瞬态 |
| 5A（TLP） | 6.5V | 临界 | 已到边界 |
| 6A（8/20µs） | 7.6V | **✗** | 超过 6.5V 约 1.1V |
| 16A（TLP） | 7.6V | **✗** | 大能量事件需另加措施 |

**若后续实测事件能量确实到几 A 级**，可按以下两条加强（均作用于保护器件侧）：

1. **换更高输入耐压的 LDO**（18V/36V 输入级）：把 6.5V 约束放宽到 18V，SMF5.0A 单级即可满足，钳位器件选型随之自由；
2. **加 OVP 开关**（5.8V 门限、µs 级断开）：过压时"断开"而非"钳位"，后级电压被硬性限制；代价是增加器件、压降与成本。

## 五、过流保护（保险丝）选型

**作用**：在发生击穿等低阻故障时切断持续灌流电流（防扩大、防烧板）；电压钳位由第四章的钳位器件负责。

**放置位置**：串在 **VCC5V 与 U3 VIN 之间（LDO 输入支路）**。该支路在主机/从机两种变体下都只有 ≤80mA，因此：

- 不受从机侧 1.5A DUT 供电电流影响，**一个规格即可覆盖两种变体**，无需贴装区分；
- 共用 VBUS 通路（U4/U5 → DUT）保持原状，不影响 DUT 供电能力。

**表 5-1　保险丝规格**

| 支路 | 稳态电流 | 推荐规格 | 说明 |
| --- | --- | --- | --- |
| LDO 输入支路（VCC5V → U3） | **≤80mA**（主机/从机相同） | **0.25A** 慢熔或 PTC | PC 口限流 ≤0.5～0.9A 时可在秒级熔断 |

**配套改动**（保证保护链顺序正确）：

| 项 | 做法 |
| --- | --- |
| 器件与电容布置 | ESD441DPLR 与本地电容（≥1µF，建议 10µF）均放在 **LDO 侧**（保险丝之后、紧贴 U3 VIN）；现有 C8/C13 在 VCC5V 侧，需移一颗过去 |
| 脉冲耐受 | 钳位器件的瞬态电流经过保险丝：5A/20µs 的 I²t≈5×10⁻⁴ A²s，远低于 0.25A 慢熔保险丝耐受值，不会误断 |

**保护链分工**：短时瞬态由钳位器件吸收；持续过压/短路由保险丝隔离该支路。

**从机侧 1.5A 供 DUT 的核对项**（与保险丝位置无关，但同属本次评审；该电流已超出 USB 2.0 标准口 0.5A）：

| 项 | 需要确认 |
| --- | --- |
| F2（VCC5V_OUT→VCC5V） | 额定电流 ≥2A（1.5A DUT + 80mA 板内），现值需核对 |
| U4/U5 磁珠 | 1.5A 经两个 VBUS 脚分流，**每颗约 0.75A**，须在额定电流内 |
| U2 降压 + L4 | 能否持续输出 1.5A + 80mA（决定 DUT 供电能力上限） |
| VBUS 路径铜箔/过孔 | 1.5A 下的压降与温升 |

## 六、LTspice 仿真清单

**表 6-1　器件等效模型**（按规格书曲线反推，均已与手册点校验）

| 器件 | 膝点 V_BR_eff | R_DYN | 校验 |
| --- | --- | --- | --- |
| ESD441**DPL** | 6.2V | 0.09Ω | 1A→6.3V ✓ 5A→6.5V ✓ 16A→7.6V ✓ |
| ESD441**DPY** | 7.0V | 0.075Ω | 1A→7.1V ✓ 5A→7.3V ✓ 16A→8.2V ✓ |
| SMF5.0A | 6.7V | 0.115Ω | 21.7A→9.2V ✓ |
| RCLAMP0521T-ES | 8.0V | 2.0Ω | 1A→10V ✓ 4A→16V ✓ |

```text
* 行为源写法（LTspice）
B2 LDO 0 I = 0.05*ln(1+exp((V(LDO)-6.2)/0.05))/0.09     ; ESD441DPL
B1 VCC 0 I = 0.05*ln(1+exp((V(VCC)-6.7)/0.05))/0.115    ; SMF5.0A
```

**表 6-2　必须包含的要素**

| 要素 | 建模方式 | 为什么 |
| --- | --- | --- |
| 端口 / 线缆 | 5V 源 + 0.1～0.2Ω + 线缆 L 0.5～1µH | 热插拔振铃的能量来源 |
| 磁珠 / 电容 / 负载 | 厂家 Z(f) 等效（R+L）+ DCR；电容**按 DC 偏压降额**（6～7µF）+ ESR；负载取 LDO 输入电流（≤80mA） | 理想电感会高估滤波；降额与负载决定实际波形 |

**源与扫描角**：源取 ① IEC 61000-4-5 组合波（2Ω）② 硬阶跃（0.1Ω）③ 6.5/7/9V 三档 ④ 热插拔 0→5V；扫描角取 V_BR 三档（DPL 6.2/6.7/7.2V）｜C 两档（11µF / 6.5µF 降额）｜磁珠两档｜温度 −40/25/85℃。

**判据**：V(LDO) 峰值 **<6.5V**，且超 6.5V 的时长/能量落在实测无害区（后者由第七章台架给出 SOA）。**建模要点**：钳位器件用行为源表示 V-I 曲线；磁珠取厂家 Z(f) 等效；电容取 DC 偏压降额值；源含端口阻抗与线缆电感。

## 七、验证矩阵（仿真 → 台架）

| 项 | 方法 | 通过判据 |
| --- | --- | --- |
| 过压 / 浪涌 | 6.5/7/9V 直流步进（每级 60s、限流 100mA）；8/20µs、10/1000µs、1ms 方波各 10 次，逐级加严 | 3.3V 输出保持；LDO 侧峰值 <6.5V；U3 无损 |

| 短路注入 / 反接 | 人为短接 LDO 输入；VBUS/GND 反接 | 保险丝动作、板面无烧蚀；后级无损（单向器件为牺牲件） |
